# decli.github.io

MT 通商 · TRADEFLOW —— 外贸业务管理系统的在线演示。

**打开 → <https://decli.github.io/>**

这个仓库只放构建产物。**源码在 [decli/ForeignTradeManagementSystem](https://github.com/decli/ForeignTradeManagementSystem)**，
更新方式是在那边跑：

```bash
npm run deploy
```

它会用 `base=/` 构建，然后把 `dist/` 推到这里。不要直接改这个仓库里的文件 ——
下一次部署会整个覆盖掉。

演示账号 `admin` / `demo1234`。数据存在你自己的浏览器里，不上传任何东西。
